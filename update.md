# 🚀 GitHub Release - Lantern v3.0

Этот файл можно использовать как готовую памятку при публикации релиза на GitHub.

## 🏷️ Что заполнить в GitHub

- **Choose a tag:** `v3.0` - создать новый тег.
- **Target:** `master`.
- **Release title:** `Lantern v3.0`.
- **Set as the latest release:** включить.
- **Set as a pre-release:** не включать.

## 📦 Что прикрепить к релизу

Основной файл для пользователей:

- `_installer/Lantern-Setup.exe` - установщик Lantern 3.0 для Windows x64.

Дополнительно можно прикрепить portable-версию:

- `Lantern.exe` - приложение без установщика.

Важно: имя основного файла оставить именно `Lantern-Setup.exe`. Приложение использует это имя при поиске нового установщика.

## 📝 Текст для Release notes

```md
## 🚀 Lantern 3.0

Крупное обновление интерфейса, загрузки компонентов и стабильности.

### 🎨 Интерфейс

- Обновлены SVG-иконки в едином стиле Material Symbols Rounded.
- Google Sans используется в интерфейсе, Google Sans Code - в журнале событий.
- Шрифты загружаются автоматически при первом запуске и проверяются по SHA-256.
- Улучшены анимации запуска zapret и Telegram Proxy.
- Сворачивание бокового меню стало плавнее, а активные пункты в свёрнутом состоянии теперь квадратные.
- Внутренние уведомления складываются в стек и больше не перекрывают друг друга.
- Избранные стратегии получили понятный переключатель со звездой и отдельный фильтр.

### 📋 Журнал и диагностика

- Журнал стал информативнее: точное время до миллисекунд, уровни INFO, OK, WARN и ERROR, цветовая индикация, поиск, фильтрация, пауза, копирование и сохранение.
- Улучшены сообщения о запуске, остановке и ошибках компонентов.

### 📥 Компоненты и загрузка

- zapret скачивается из последнего официального GitHub Release и автоматически распаковывается в приложение.
- TG Proxy скачивается и обновляется из приложения. Перед обновлением старый процесс корректно останавливается.
- Добавлена ссылка на репозиторий TG Proxy на странице «О проекте».

### 🛠️ Исправления и стабильность

- Исправлены проблемы с определением состояния службы zapret.
- Остановка winws теперь затрагивает только процессы текущего приложения.
- Исправлены автозапуск, работа IPSet, обработка профилей и параллельные операции запуска.
- Улучшены сетевые проверки, таймауты и обработка ошибок загрузки.
- Загрузка файлов происходит через временный `.part`-файл, поэтому рабочие файлы не портятся при обрыве сети.

### 💻 Установка

1. Скачайте `Lantern-Setup.exe` из Assets.
2. Запустите установщик от имени пользователя Windows.
3. Для запуска zapret и работы со службой потребуются права администратора.
```

## ✅ Проверка перед публикацией

- Убедиться, что прикреплён `_installer/Lantern-Setup.exe`.
- Убедиться, что тег и заголовок содержат `v3.0`.
- Скачать Asset со страницы черновика и проверить, что установщик запускается.
- После публикации открыть `https://github.com/krinix1337/lantern-zapret/releases/latest` и убедиться, что отображается `Lantern v3.0`.
