# 📖 Руководство по Lantern

*Коротко о каждом разделе приложения и его работе.*

[🏠 Главное](../README.md#main) · [🎨 Темы](themes.md) · [🚀 Установка](../README.md#installation)

</div>

Lantern — графическая оболочка для `zapret` и `winws.exe` в Windows. Она помогает выбрать стратегию обхода, запустить её вручную или как службу, проверить соединение и посмотреть журнал работы.

> 💡 Начните с выбора стратегии, затем запустите обход на главном экране и проверьте доступность нужных сервисов.

---

## 🛡️ Перед началом

- 🔐 Запускайте Lantern от имени администратора: это нужно для `WinDivert`, службы Windows и DNS-over-HTTPS.
- 🔄 После изменения игрового или IPSet-фильтра перезапустите обход либо службу, чтобы новые параметры попали в запуск `winws.exe`.
- ⚠️ Не запускайте параллельно несколько копий `winws.exe` из разных папок: это может вызвать конфликт драйвера и порта.

## 🏠 Главное

На главном экране находятся состояние zapret, выбранная стратегия, способ запуска и время работы. Кнопка запуска включает выбранную стратегию вручную; кнопка остановки завершает запущенный обход. Отдельная карточка показывает состояние TG Proxy и позволяет его включить или выключить, если компонент установлен.

Если zapret ещё не установлен, Lantern предложит скачать его из официального релиза. После установки выберите стратегию и вернитесь на главный экран для запуска.

## 🧩 Стратегии

Здесь отображаются доступные `.bat`-стратегии из папки zapret. Выберите одну — она станет текущей, но не начнёт работать до запуска на главном экране или установки службы.

У каждой стратегии есть кнопка-звезда. Звёздочка добавляет вариант в избранное: такие варианты закрепляются вверху списка и их проще сравнивать. Описание под названием объясняет назначение параметров, но не меняет содержимое исходного BAT-файла.

## 🔎 Проверка соединения

Раздел содержит проверки сервисов и стратегий.

- 🌐 **Сервисы и игры** — проверяет выбранные адреса через DNS, HTTP и TLS, показывая доступность и ошибку при сбое.
- 🧪 **Проверка стратегий** — временно запускает `winws.exe` для выбранной стратегии, проверяет несколько адресов и затем останавливает процесс. Можно тестировать одну, несколько или все стратегии.

Проверка стратегий временно останавливает текущий обход, потому что одновременно можно надёжно проверять только один экземпляр `winws.exe`. Сохраните работающий вариант в избранное до экспериментов.

## ⚙️ Служба Windows

Служба запускает выбранную стратегию автоматически вместе с Windows. В этом разделе можно выбрать стратегию для службы, установить и запустить её, остановить или полностью удалить.

Для установки нужны права администратора. Если служба уже работает, не запускайте одновременно ручной обход на главном экране: служба и ручной запуск должны использоваться по очереди.

## 🎛️ Фильтры

Фильтры соответствуют настройкам `service.bat` и изменяют параметры следующего запуска.

- 🎮 **Игровой фильтр**: выключен, TCP + UDP, только TCP или только UDP. Он добавляет обработку игрового трафика в выбранном режиме.
- 📋 **IPSet-фильтр**: использовать загруженный список, отключить список или обрабатывать все адреса. Список можно обновить из самого раздела.
- 🔒 **DNS-over-HTTPS**: включает или выключает DoH через настройки Windows. Эта операция требует прав администратора и перезапускает DNS-кэш.

Меняйте параметры по одному, затем перезапускайте обход и проверяйте результат в разделе проверки соединения.

## ⚙️ Настройки

В настройках выбираются язык, тема, поведение окна, параметры проверки и профили. Профиль сохраняет выбранные стратегию, игровой фильтр, IPSet и DoH, чтобы быстро вернуться к рабочему набору.

При старте приложение проверяет доступные версии zapret, TG Proxy и Lantern через GitHub. Статусы и номера локальной/последней версии остаются в настройках. Если для конкретного компонента доступен настоящий новый релиз, рядом появляется кнопка обновления, которая скачивает официальный файл GitHub.

Проверка не делает версию "актуальной" искусственно: если версия на GitHub старее локальной, это отображается как более старая, а не как обновление.

## 🎨 Темы

Тема переключается сразу, без перезапуска. Доступны тёмная, AMOLED, светлая, «Северное сияние» и «Питер Гриффин». Страница со скриншотами и описаниями: [Темы Lantern](themes.md).

У темы «Питер Гриффин» появляется отдельная настройка с иллюстрацией и управлением музыкой. Кнопка воспроизводит случайный MP3 из папки `assets/peter-songs`; кнопка остановки завершает воспроизведение. В поставке есть предоставленная композиция, а добавленные в эту папку MP3 автоматически участвуют в случайном выборе.

## 📋 Лог

Журнал отображает события запуска, остановки, проверки и сообщения `winws.exe`. Время указано без миллисекунд, чтобы строки легче читались. По цвету можно быстро отличить обычное сообщение, предупреждение и ошибку.

Если обход не запускается, сначала откройте журнал, затем проверьте, что Lantern запущен от администратора, стратегия выбрана и служба не заняла `winws.exe`.

## ℹ️ О программе

В разделе собрана информация о версии Lantern, компонентах, лицензии и проверке целостности. Проверка SHA-256 помогает убедиться, что файлы соответствуют опубликованным контрольным суммам.

> 🛡️ Скачивайте zapret и TG Proxy только из официальных GitHub-релизов. Не используйте сторонние сборки и не отключайте защиту Windows ради запуска неизвестного файла.
