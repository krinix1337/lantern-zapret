> ✨ Все скриншоты сделаны из собранного приложения. Тему можно выбрать в **Настройки → Интерфейс → Тема оформления**; переключение применяется сразу, без перезапуска.

---

## 🌙 Тёмная

Спокойная базовая тема для повседневной работы: нейтральный графитовый фон и синий акцент.

![Главный экран — тёмная тема](themes/overview-dark.png)

## 🖤 AMOLED

Максимально чёрный фон для OLED-экранов и работы в темноте, с сохранением читаемых границ карточек.

![Главный экран — AMOLED](themes/overview-amoled.png)

## ☀️ Светлая

Контрастная светлая тема для дневного освещения и ярких мониторов.

![Главный экран — светлая тема](themes/overview-light.png)

## 🌌 Северное сияние

Новая тёмная тема: глубокий зелёный фон, мягкий мятный акцент и тёплые статусы. Она создана для долгой работы без резких ярких цветов.

![Главный экран — Северное сияние](themes/overview-aurora.png)

## 🍗 Питер Гриффин

Светлая тема с небесно-голубым фоном, зелёными акцентами и полупрозрачной иллюстрацией Питера Гриффина на фоне рабочей области.

![Главный экран — Питер Гриффин](themes/overview-peter.png)

> 🎵 Только в этой теме доступны дополнительная настройка с иллюстрацией и случайное воспроизведение MP3 из `assets/peter-songs`.
